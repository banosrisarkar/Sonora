# Sonora — Personal Music & Playlist Studio

Sonora is a portfolio-ready music library and playlist studio.

## Features
- Unlimited playlists
- Add unlimited local audio files you own or are authorized to use
- Play/pause/seek/volume
- Shuffle and repeat
- Queue and next/previous
- Favorites
- Search
- Custom playlist covers, colors, moods and descriptions
- Browser persistence with IndexedDB
- Responsive design
- Release-to-Spotify / YouTube UI with safe integration instructions

## Important licensing note
Sonora does not provide a catalog of copyrighted music. Only upload audio you own or are authorized to use. Official Spotify/YouTube integrations should create playlists in the user's own accounts through their APIs; they should not copy or redistribute those services' music.

## Run
1. Open this folder in VS Code.
2. Install the Live Server extension.
3. Right-click `index.html` → Open with Live Server.
4. Add your own/authorized audio files.
